# ZALA · Operator — ANON × ConsMAP × GHOSTCORE

A single, self-contained, **offline** app that unifies the ANON corpus, the ConsMAP
discipline, and Zala's GHOSTCORE portal into one forensic descent.

## Run it
Open `app/index.html` in any browser — no server, no network, no build step needed.
Everything (chapters, evidence, art, portals) is embedded in the one HTML file and
works from `file://`.

## Rebuild it
```bash
python3 build_zalasite.py
```
The generator reads the ANON corpus + `source_lock/` and the ConsMAP operator repo
**strictly read-only**, and writes **only** into `app/`. It never modifies ANON or
ConsMAP.

- ConsMAP operator: `/home/saba/VES/ACTIVE_PROJECTS/ZavestMAP/ConsMAP_operator_v2_3`

## Controls
- **Register dial** — Mythos / Both / Logos (rail, or keys **M / B / L**): governs how
  much parable vs plain-claim you see, app-wide.
- **🔦 Print · lights on** — prints the current view in the active register.
- **? Field guide** — keyboard map, tier/river/gatekeeper legends, ConsMAP concepts
  (press **?**).
- **← → / j k** — page chapters in Read. **Esc** — close overlays.
